# Security Policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, email **hello@artslaw.io** with a description of the issue, steps to
reproduce, and the potential impact. You will receive a response as soon as
possible, and we ask that you give us a reasonable window to fix the issue
before any public disclosure.

## Scope

- This repository (client and server code)
- The deployed service at https://www.artslaw.io

Out of scope: denial-of-service testing against the live service, and issues in
third-party services we depend on (Clerk, MongoDB Atlas, Anthropic, Mistral,
Tavily) — please report those to the respective vendors.
